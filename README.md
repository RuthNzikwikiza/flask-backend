# Flask Backend

A lightweight and powerful Flask backend API that serves as the server-side of a full-stack application.  
It handles API requests, processes data, and sends responses to the frontend.

## Features
- RESTful API endpoints  
- Handles requests and returns JSON responses  
- CORS support for frontend integration  
- Environment variable support using `.env`  
- Fast, minimal, and easy to deploy on Render or any cloud platform  


## Technologies Used
- Python  
- Flask  
- Flask-CORS  
- Flask-RESTful 
- python-dotenv  
- Gunicorn (for deployment)
